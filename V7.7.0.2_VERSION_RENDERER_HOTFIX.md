# v7.7.0.2 Version Renderer Hotfix

Root cause:
v7.7.0.1 temporarily had two version renderers:
1. the legacy real DOM `#app-version-note`
2. new per-view pseudo-element footers

The legacy JS also continued to reparent the real node between views.

Fix:
- All pseudo version footers are retired.
- The original `#app-version-note` is the only version renderer.
- It stays in one permanent global DOM position after all app views.
- `placeAppVersionNote()` is now intentionally a no-op.
- During protected Profile push/pop the version is hidden from the geometry
  transition and appears once at its final settled position.
- Expense uses the same global renderer with bottom-nav clearance.

No Firestore Rules or index changes.
The v7.3.13 navigation compositor is unchanged.
