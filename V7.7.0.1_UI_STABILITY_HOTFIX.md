# v7.7.0.1 UI Stability Hotfix

## Profile push animation style jump
The protected v7.3.13 compositor intentionally removes IDs from snapshot
clones. Later CSS relied on IDs, so snapshot and live page used different
styles during the transition.

Fix:
- App/Data page selectors now use `data-profile-page="app-data"`.
- Profile helper/status text uses `.profile-nav-page`.
- Class/data selectors survive cloning, so snapshot and live render the same.
- The v7.3.13 compositor itself is unchanged.

## Version footer jump
The old single version DOM node was reparented between views, and Expenses
could reparent it a second time after module mount.

Fix:
- Legacy version node is hidden.
- Each view paints a stable footer at its own final content end.
- Expenses paints the version after `.expenses-app` content.
- During Profile push/pop the footer is withheld from the geometry swap and
  appears once at the final settled position.

No Firestore Rules or index changes from v7.7.0.
