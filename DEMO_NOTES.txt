Travel Webapp Phase 1 v7.0.4 demo

This lightweight package uses demo assets.

Changes in this build:
1. Root canvas and background are full bleed; theme-color tinting is removed.
2. Safe-area padding applies to foreground content, not the page background.
3. Six-day selector is a fixed equal-width grid aligned to the compact title.
4. Longer trips automatically fall back to horizontal day scrolling.
5. Saved-item sheet supports interactive downward drag and swipe dismissal.
6. Sheet backdrop follows the gesture and snaps back below the dismissal threshold.

For iOS Home Screen testing after manifest/status-bar changes, remove the old icon and add the web app to the Home Screen again.
